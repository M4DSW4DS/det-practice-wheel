# DET Practice Wheel — Testing Checklist (v1.4)

> Живой файл. Отмечай после каждого блока фиксов.
> Легенда: `[ ]` — не проверено, `[x]` — ок, `[!]` — баг.
> Автопрогон: `?selftest=1` (UI на фейковом API, базу не трогает) и `?autotest=1` (реальное чтение Supabase, read-only).

## 1. Игра

- [ ] Спин: карточки крутятся ~6 с, кнопка ENTER скрывается и возвращается.
- [ ] После остановки карточка мигает (gold / blue / flash) и звучит соответствующий звук.
- [ ] START TASK → «TASK IN PROGRESS» → I FINISHED IT → XP начислен, прогресс +1.
- [ ] Достижение 6/6 → модалка SKILL MASTERED, +1000 XP.
- [ ] POWER MOVE из инвентаря → +300 XP сразу.
- [ ] LUCKY BREAK → выбор любого скилла → открывается задание.
- [ ] SHIELD пассивен (алерт), при коте снимается и блокирует кражу.
- [ ] Кот в мешке: 25% шанс, прогресс сохраняется, счёт не растёт.
- [ ] Колесо не застревает после 20+ спинов подряд.

## 2. Мобильные экраны (≤768px)

- [ ] Три экрана: PLAYERS → WHEEL → PROGRESS, свайп в обе стороны, цикл.
- [ ] Переключение экрана с лёгким слайдом (~240 мс).
- [ ] Логотип `D.E.T` по центру, не перекрыт иконками.
- [ ] Бейдж игрока слева сверху: аватар + счёт, цвет = цвет карточки.
- [ ] Активная буква логотипа увеличивается.
- [ ] После F5 открывается тот же экран.
- [ ] Поворот телефона не ломает позицию барабана.

## 3. Карточки и права

- [ ] Все карточки в одну вертикальную колонку (и на телефоне, и на ПК).
- [ ] 4+ карточек: список прокручивается, горизонтального выезда нет.
- [ ] На карточке: аватар, счёт, имя, «now / 5m / 3h», инвентарь, XP-бар.
- [ ] Своя карточка помечена `· me` (когда Shared tablet выключен).
- [ ] Тап по чужой карточке → экран скиллов друга, колесо скрыто (мобилка).
- [ ] Свайп на экране друга → сразу PLAYERS, минуя колесо.
- [ ] Повторный тап по карточке друга / тап по бейджу → выход на своё колесо.
- [ ] На десктопе при просмотре друга колесо и карточки на месте, справа его прогресс.
- [ ] Своя карточка крутится, счёт растёт, в Supabase меняется только моя строка.
- [ ] На десктопе Shared tablet всегда включён, кнопки тумблера нет.
- [ ] На телефоне Shared tablet: нажал — синяя, ещё раз — серая.

## 4. Идентичность и друзья

- [ ] Новый браузер → модалка «WHO ARE YOU?».
- [ ] Создание карточки: имя + аватар → карточка появилась, в базе новая строка.
- [ ] INVITE по аватару: QR + код вида `Code: xxxxxxxx`.
- [ ] Друг открывает `?join=<код>` → создаёт карточку → «Connected to …».
- [ ] После подключения видны только своя карточка и пригласивший (и его связи).
- [ ] «Sign in with code» со своим кодом → вернулся прогресс и друзья.
- [ ] `?player=2` на карточку БЕЗ имени → привязка работает.
- [ ] `?player=2` на карточку С именем → открывается «WHO ARE YOU?», чужая строка не подхватилась.

## 4. Просмотр друга и приглашения
- [ ] Тап по чужой карточке → бейдж показывает друга, экран PROGRESS с его скиллами.
- [ ] Свайп работает по всем трём экранам, как обычно.
- [ ] На экране WHEEL колесо видно, но заблокировано полупрозрачным оверлеем «VIEWING <имя>».
- [ ] Оверлей не пропускает спин (ENTER не нажимается).
- [ ] Тап по оверлею → возврат на свою карточку.
- [ ] Invite: QR, крупный код, Copy Invite Link.
- [ ] iOS/Safari (нет BarcodeDetector): кнопка Scan скрыта, показана подсказка про камеру телефона.
- [ ] Android Chrome: кнопка Scan видна, открывается камера с превью, QR считывается.
- [ ] Manage friends → Remove: друг исчезает и у тебя, и у него (после обновления).
- [ ] Если DELETE-политики нет — Remove показывает ошибку, а не врёт.

## 5. Синхронизация

- [ ] Чип снизу слева: `⏳` скрыт, `🔵 synced` виден ~2 с, потом исчезает.
- [ ] Задание выполнено → в Supabase `score`/`progress`/`updated_at` обновились у моей строки.
- [ ] Нет сети → `🟡 local only` + баннер «Local only» с Retry.
- [ ] Retry после возврата сети → `🔵`, локальные изменения ушли в облако.
- [ ] Клик по чипу → Diagnostics (read-only отчёт).
- [ ] Settings → Sync now: при чистом стейте подтягивает облако, при грязном — отправляет.

## 6. Сброс и настройки

- [ ] Settings: Shared tablet / Change name / Manage friends / My code / Join a friend / Switch account / Sync now / Reset progress / Logout / Close.
- [ ] Reset спрашивает по имени карточки («Reset progress for VOVA?»).
- [ ] После сброса обнулилась только активная карточка, соседние сохранили счёт.
- [ ] Change name меняет имя активной карточки и уходит в облако.
- [ ] Logout забывает карточку на устройстве, в облаке она остаётся; вход по коду возвращает.
- [ ] Внизу Settings — `DET Practice Wheel · v1.7`.

- [ ] После создания карточки сразу открывается YOUR CODE с крупным кодом.
- [ ] Settings → My code: код и кнопка «Copy personal link» (`?me=…`).
- [ ] Открыть `?me=<код>` в другом браузере → устройство привязалось к той же карточке, модалка «WHO ARE YOU?» не появилась.
- [ ] Settings → Switch account → код с другого устройства → прогресс и друзья подтянулись.
- [ ] Settings → Join a friend → вставить код → друг появился в списке (без перехода в браузер).
- [ ] На iPhone: PWA и Safari показывают разные карточки (это нормально), но через My code / Switch account переносятся.
- [ ] В модалке «WHO ARE YOU?» видно предупреждение про второй аккаунт.

- [ ] Десктоп: три колонки, ничего не обрезано, рамки карточек целые.
- [ ] Клавиши: Enter/Space (спин), H (настройки), S (звук), ←/→ (игрок), Esc (закрыть).
- [ ] Мобилка: все экраны, свайпы в обе стороны зациклены.
- [ ] Два устройства: прогресс сходится в обе стороны.
- [ ] Консоль: ноль ошибок (кроме блокировки vibrate/Audio до первого тапа — это норма).
- [ ] `?selftest=1` → PASS.
